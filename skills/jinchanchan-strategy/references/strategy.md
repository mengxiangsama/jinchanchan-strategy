# 决策与攻略交付

## 完整阵容方案

按用户熟悉程度压缩说明，但不要只列最终英雄名字：

- **身份与条件**：适用赛季/补丁/模式，适合的来牌、散件、强化；何时不应玩。
- **阵容**：目标人口、每名棋子、主 C/主坦/副 C、关键羁绊、过渡和替代卡。人数与羁绊需逐项核对，转职和特殊上场规则单列。
- **装备**：主 C 和主坦的优先成装、可替代装备、散件优先级；替代装说明取舍。效果和合成公式必须属于目标版本，转职/专属装备不可假设可合成。
- **强化/赛季机制**：适配理由、不能兼容的选择；只有该模式存在的机制才讨论。
- **运营**：前期过渡、中期稳定、关键升级/搜牌决策、后期转型。节点随血量、经济、商店概率和模式调整，不把“某回合必升人口”写成跨版本定律。
- **站位**：前后排、保护主 C、针对突进/控制/范围技能的调整。只在棋盘布局已确认时用带方向说明的格子图，不能凭记忆标坐标。
- **退路**：关键牌不来、有同行、装备偏离、血量过低时怎么止损。
- **证据**：适用版本、来源链接、统计限制；主观排序标成判断。

阵容码只有从匹配版本的可验证来源取得或有实际可用编码器并验证成功时提供，不能编一个看起来像编码的字符串。

## 来牌与局面判断

先提取可见状态：阶段/倒计时、血量、金币、等级/经验、棋盘和备战席、商店、装备、强化、同行。看不清的字段标未知，不能从图标颜色猜定角色。

把选择收敛为“本回合先做什么 / 为什么 / 满足什么条件再改”：

1. 检查场上是否少上单位、存在可立即合成的升星或明显功能缺口。
2. 评估当前战力与失血风险，再决定存钱、升级、少量搜牌或集中提升。不要只因为攻略写了固定回合就花空金币。
3. 追三星前看持牌数、费用对应的该版本商店概率、同行、剩余卡池信息与替代收益；没看到卡池就不能编成功概率。
4. 合装备前核对目标携带者、已有装备/槽位和未来替换方式，避免靠未经确认的拆装机制制定计划。
5. 对双人/狂暴/恭喜发财等先读该版本规则；单人经济与人口节奏不能直接套用。

## 镜像延迟下的选择

优先简单、容错高、需要切屏较少的方案；不是为方便操作而强行采用弱阵容。每回合先处理最高价值动作，接近倒计时结束就停止复杂转型，必要时请用户接手。攻略知识不能消除网络/截图/执行延迟。

## 复盘

区分“当时可见信息下的决策”和“事后才知道的结果”。记录阶段、已知局面、实际选择、可替代动作、收益风险和不确定性；不能用一次输赢证明整套策略无效或有效。优先指出一到三个可改进的决策，不需要编造完整战报。
