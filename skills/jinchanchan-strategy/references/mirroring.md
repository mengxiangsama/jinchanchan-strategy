# 手机镜像辅助

仅在用户明确要求查看或操作手机/游戏时读取。技能不是按键宏；操作范围由本次请求决定，且服从宿主工具权限和游戏规则。

## 连接与观察

- 使用当前环境提供的 UI 控制工具，先读工具文档；没有工具就请求截图，不能用未授权接口代替。
- macOS iPhone 镜像的应用路径为 `/System/Applications/iPhone Mirroring.app`。它只是应用定位信息，不是用户私有路径。优先按名称选择，必要时使用该路径。
- 若显示“iPhone 使用中”“锁定 iPhone 以连接”，请用户锁屏，不能从 Mac 绕过手机锁定。密码、双重认证、首次安全授权由用户处理。
- 镜像的可访问性树可能只有窗口和菜单，此时用截图定位。可用快捷键、点击、滚动或拖动只采用当前工具文档明确支持的方式。
- 已验证当前会话存在时复用绑定；出现“not active”“user changed”则重新获取应用和画面，不重放旧坐标。
- 横屏切换、窗口缩放、页面跳转后坐标失效。每组动作后观察新状态，再决定下一步。

## 操作规则

1. 进入游戏只关闭明确的展示弹窗；不要点“立即前往”进商城、召唤或抽奖。按钮模糊先看清，不把右上角任意图标当关闭。
2. 开始匹配前确认模式；“开始游戏”登录按钮与“开始对局”不同。用户没要求排位不能自选排位。
3. 每轮操作前确认当前界面和倒计时；买棋子看商店与金币，摆位看目标棋盘格，合装看携带者与槽位。
4. 采用短批次“观察 → 决策 → 动作 → 验证”。商店刷新会改变位置，不允许按旧截图连续买牌；切屏后重新识别。
5. 自动合星、战斗开始、备战席满等会改变预期，必须在下一次状态读取后调整。
6. 两次尝试同一动作仍无可见结果时换方法或说明阻碍，不能无限点击。镜像输入失败就改用可见图标导航或请用户输入，不循环重试剪贴板。
7. 倒计时不足、持续画面延迟、设备掉线、界面不可辨认或用户接管时停止盲操作，给用户一句可立即执行的建议。
8. 一局请求到结算/明确结束就停止，不自动续排。不投降、退赛、删除账号或修改安全设置。

## 验证与交接

“点击了”不等于“成功了”：打开游戏看启动/大厅，匹配看队列，对局动作看金币/棋盘/装备，结束看结算。说明已做、未做与延迟影响，不伪造战绩。发生限制时交还用户，不承诺无人值守。

当前技能不含游戏录像、账号或固定机型坐标，也不绕过镜像权限或反作弊。
